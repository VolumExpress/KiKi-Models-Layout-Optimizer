# KiKi Models Layout Optimizer

**Open-source 2D layout optimizer for Adobe Illustrator**

**KiKi Models Layout Optimizer** helps arrange vector objects on engraving and cutting plates, optimize spacing, and organize families of symbols by size and shape.

**KiKi Models Layout Optimizer** — открытый инструмент для автоматической раскладки векторных объектов в Adobe Illustrator. Поддерживает оптимизацию плотности, равномерности зазоров и группировку эмблем по семействам.

## Important / Важно

This is beta software. It is not a CAM system and does not generate validated machine-ready laser toolpaths.

Программа находится в стадии бета-тестирования. Перед изготовлением пластин необходимо проверять геометрию и технологические ограничения.
