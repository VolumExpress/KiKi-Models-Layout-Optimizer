# KiKi Models Layout Optimizer v0.7.2 (бета)

[Главная](README.md) · [English](README_EN.md)

**Назначение.** Помощник по размещению произвольных векторных контуров на листе/пластине в Adobe Illustrator. Умеет гравировку и экспериментальное размещение деталей для резки. Не является CAM и не управляет лазером.

## Новое в v0.7.2 — упорядоченные семейства

**Что выбрать:** «Группировка» отвечает за обнаружение похожих эмблем; «Организация семейств» отвечает за расположение уже распознанных серий. В панели краткие пояснения находятся рядом с настройками. «Показать технические ID» нужен только для диагностики.

## Возможности

- Три базовых режима: **Dense** (минимальная рамка), **Uniform** (равномернее соседние зазоры), **Ordered** (сохранение последовательности выделения).
- Зазоры, независимые отступы с четырёх сторон, вращения 0/180/90/270°, запреты поворотов и фиксация выбранных фигур.
- Группировка по кодам, автоматическая (приблизительное сходство силуэтов) или отключённая. Автоматические семейства проверяйте визуально: похожие, но различные эмблемы могут объединиться.
- Многократные попытки, seed, мягкий лимит времени, экспериментальный LNS/NFP и **v0.7.1 экспериментальное управление поиском весами (выключено по умолчанию)** площади/зазоров/условных переходов. Веса не обещают глобальный оптимум.
- Pareto-предпросмотры: сохраняются в `workspace/<документ>/alternatives/`, **только для просмотра**. Применить можно лишь финальный проверенный `result_test.json`.
- Безопасный повторный экспорт: архив истории, перенос ограничений только при совпадении UUID/геометрии, сброс устаревшего результата.
- Профиль резки учитывает ширину пропила и положительную перемычку между **раздельными** контурами. Общие линии обнаруживаются аудитором. `shared_cut_preview` может получить **черновик уникальной линии** для уже соприкасающихся исходных простых полигонов, без компенсации пропила и без CAM.

## Совместимость

- Windows: **Adobe Illustrator 30.6.0.109** — пользователем подтверждены экспорт, расчёт, применение и CEP для предыдущих выпусков (v0.5.1–v0.7.1). **Полный цикл v0.7.2 UI/Docs RC1 проверен пользователем на Windows с Illustrator 30.6.0.109; macOS пока нативно не проверялась.**
- macOS: код и сценарии сборки предусмотрены, **нативный запуск не проверен**. Поддержку конкретных выпусков Illustrator необходимо испытывать отдельно.
- Интерфейс: **CEP / Extensions (Legacy)**. Будущий UXP потребует нового адаптера, Python-движок останется независимым.

## Установка для обычного пользователя (без Python)

1. Скачайте отдельный `KiKi-v0.7.2-windows-portable.zip` либо `KiKi-v0.7.2-macos-portable.zip`, **собранный на соответствующей ОС**. Архив исходников без папки `runtime` не заменяет готовый дистрибутив.
2. Распакуйте ZIP в отдельную папку. Проверьте содержимое, лицензии и контрольные суммы `SHA256SUMS.json` / `SHA256SUMS.txt`. Установщик проверяет файлы до копирования.
3. На Windows запустите `installers/windows/install.cmd`; на macOS — `installers/macos/install.command`. Установщик проверяет SHA-256 и копирует файлы в пользовательскую папку, не удаляя `workspace` и пресеты.
4. Для неподписанной бета-панели CEP потребуется **отдельное явное разрешение режима разработки Adobe (CSXS.11/12)**. Не включайте этот режим, если не доверяете коду. Подписанного производственного CEP-пакета пока нет.
5. Полностью перезапустите Illustrator и откройте **Окно → Расширения (устаревшие) → KiKi Layout Optimizer**. Если панели нет — см. [диагностику](docs/ru/INSTALL.md).

**Windows GUI-установщик:** отдельный `KiKi-v0.7.2-Windows-Setup.exe` формируется Windows-сборкой CI, если она прошла; **не включён в архив исходников**. Графический установщик тоже не включает режим неподписанного CEP без явного согласия.

## Установка из исходников / через командную строку

Требуются Python 3.10+, pip и доступ к зависимостям (`Shapely>=2,<3`). **CMake, компиляторы C++ и Visual Studio Build Tools не нужны**.

```powershell
cd kiki-layout-optimizer
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
.\.venv\Scripts\python.exe -m kiki_layout.cep_install --enable-unsigned-dev
```

macOS:

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -e '.[test]'
./.venv/bin/python -m kiki_layout.cep_install --enable-unsigned-dev
```

Флаг `--enable-unsigned-dev` добровольный; для ручной установки без него уберите флаг. Порядок запуска CLI:

```bash
python -m kiki_layout.cli workspace/example/input_copy.json -o output.json --mode dense --gap 0.8 --families named --rotations 0 --trials 4 --seed 42 --svg preview.svg
```

Для полного списка параметров — `python -m kiki_layout.cli --help`. Отдельный запуск CEP без Illustrator не даёт доступ к выделению объектов.

## Подсказки в CEP

После экспорта доступны «Быстрый старт», пояснения технологии, режима раскладки, группировки, поворотов, зазоров, организации семейств, фиксации, пресетов и приоритетов. Пользовательские подписи больше не ссылаются на «прежний алгоритм» или внутренние номера в списке семейств; при необходимости их можно открыть отдельно. Все экспериментальные функции по-прежнему отмечены как экспериментальные.

## Работа в Illustrator

На **копии `.ai`** выделите все объекты → **Экспорт выделения** → настройте технологию, зазоры, поля, группировку и повороты → **Рассчитать** → проверьте SVG, Pareto-варианты и отчёт → **Применить**. Для фиксации отдельных эмблем выделите их на холсте и сохраните ограничения через CEP. После любого изменения исходной геометрии экспортируйте заново. Применение изменяет координаты выделенных объектов; используйте отдельный файл и историю Illustrator.

## Что НЕ делает продукт

- Не гарантирует глобальную оптимальность, равную плотность везде или сохранение выбранного порядка, если это не режим Ordered.
- Не гарантирует корректное распознавание разных эмблем по силуэту.
- Не вычисляет реальное время работы лазера: «переходы» — приближение между центрами.
- Не соединяет автоматически общие резы для **новой оптимизированной раскладки** и не генерирует CAM, пропил-компенсированные управляющие траектории, заходы, перемычки, безопасный порядок реза или G-code. Векторный черновик общих исходных линий **запрещено отправлять станку как готовый файл**.
- Не включает в открытый репозиторий пользовательские `.ai`, `workspace`, реальные P10/P11, персональные журналы, токены и секреты.

## Файлы и воспроизводимость

`workspace/<имя>/input_copy.json`, `result_test.json`, `preview_test.svg`, `route_test.csv/svg`, `history/`, `constraints.json`, `alternatives/`. Параметры seed, режим, группировка, размер пластины, допуски и версия движка должны фиксироваться при сравнении. Автотесты: `python -m pytest -q`, JavaScript: `for f in tests/*.cjs; do node "$f"; done` (последнее в bash / Git Bash).
