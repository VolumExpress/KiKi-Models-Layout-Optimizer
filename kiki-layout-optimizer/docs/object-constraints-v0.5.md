# KiKi Layout Optimizer v0.5 Core Beta — закрепление, ограничения поворота, пресеты

## Статус / совместимость

Это отдельный **core beta** на базе работающих компонентов v0.4.3.
Разработка единого CEP-интерфейса v0.4.4 **ещё не завершена**: для управления
новыми ограничениями используется окно Python, вызываемое через кнопку
«Настройки и расчёт» в CEP. Экспорт/применение из CEP остаются прямыми JSX без COM.
UXP-мigration будет отдельным релизом после его доступности для Illustrator.

## Работа в Illustrator (Windows/macOS)

1. Сохраните **копию** исходного `.ai`. Установите Python-компонент через
   `install_windows.bat` либо `install_macos.command`, CEP через соответствующий
   `install_cep_*` и перезапустите Illustrator.
2. В Illustrator откройте панель KiKi (Окно → Расширения (устаревшие)),
   выделите группы для размещения и нажмите «Экспорт выделения».
   v0.5 записывает `artboard.rect_pt`, нужный для точной фиксации позиций.
3. «Настройки и расчёт» → в окне Python выберите `input_copy.json`, нажмите
   **«Ограничения объектов»**.
4. Выделите одну или несколько строк (Ctrl/Shift) по исходным индексам. Установите
   **«Не перемещать»** и/или ограничьте повороты: `global`, `0`, `0,180`,
   `0,90,180,270`. Нажмите **«Назначить выбранным»** и **«Сохранить»**.
5. Нажмите **«Рассчитать раскладку»**. Файл
   `workspace/<документ>/constraints.json` будет проверен относительно имени,
   исходных bounds и индексов объектов. При несовпадении расчёт остановится.
6. Проверьте результат SVG и затем в CEP нажмите «Применить раскладку».
   Скрипт Illustrator проверит исходное выделение/bounds перед переносом.

**Важно:** locked position означает исходное местоположение и угол **0°**
относительно export, не абсолютную привязку к текущему состоянию будущей версии
файла. Если объект уже перемещён, повторите экспорт и подтвердите новые правила.
Если исходное размещение закреплённых объектов нарушает новые зазоры/поля,
расчёт сообщит об ошибке: закреплённые объекты не будут сдвинуты.

**Составные эмблемы:** каждая исходная группа Illustrator перемещается целиком,
без изменения точек контуров. «Семейства» с закреплёнными объектами будут
разделены; при несовместимых углах между членами одного семейства оно тоже
разделится на независимые объекты с предупреждением.

## Пресеты (двуязычный UI)

Кнопки **«Сохранить пресет»** / **«Загрузить пресет»** записывают общие параметры
в `presets/*.json` (путь выбирается через стандартное окно). Это режим, зазор,
отступы, группировка, разрешённые общие повороты, гравировка/резка, kerf,
обход и т. д. **Пресеты не содержат геометрию, индивидуальные правила или
позиции объектов**. Для индивидуальных ограничений нужен `constraints.json`
в папке конкретного документа.

Обновлённые `input_copy.json`, `constraints.json`, `result_test.json` являются
производственными промежуточными данными, не публикуйте их в открытом GitHub.
Все переводы сохранены: язык окна Python выбирается в его верхней части;
язык сообщений JSX задаёт `illustrator/set_language.jsx`.

## Точность и ограничения

- Точки кривых аппроксимируются полилиниями при экспорте; конечный аудит
  выполняйте по нативной геометрии в Illustrator.
- В режиме Cut остаётся **только** kerf-aware разнос объектов, без общей линии
  реза, мостиков, lead-in/out и машинного тракта.
- Нельзя автоматически переносить правило `lock_position` из одного AI-документа
  на другой: проверяются имя и исходные габариты объекта.
- При невозможной укладке с фиксированными объектами программа завершает
  расчёт с ошибкой, не записывая новый `result_test.json`.
- 0.8 мм и отступы 2 мм — параметры тестов, не утверждённые нормы.

## For English-speaking users

In the Python panel choose **Object rules** to lock original positions or restrict
allowed rotations for individual selected entries. Settings are stored beside that
exact export in `constraints.json` and validated against source bounds and names.
Use **Save preset / Load preset** to store global options only. CEP still opens the
Python dashboard in this beta; a unified CEP UI is planned separately.

### Для CLI

`kiki-layout input_copy.json --mode uniform --families named --rotations 0,90`
автоматически загрузит соседний `constraints.json` (если он существует).
Для диагностического запуска без локальных правил укажите `--no-constraints`.
Это обходит пользовательские ограничения, поэтому не используйте такой результат
для финального применения без визуальной проверки.
