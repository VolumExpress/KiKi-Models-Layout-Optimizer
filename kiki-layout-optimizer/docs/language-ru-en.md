# Языки интерфейса — Русский / English

## Панель Illustrator (основной способ)

Откройте KiKi Models в **Окно → Расширения (устаревшие)**. В правом верхнем углу нажмите **EN** для английского или **RU** для русского. Названия режимов, справка, основные статусы и подписи отчёта семейств переключаются прямо в панели; текущая геометрия и сохранённые координаты от языка **не зависят**.

Для изменения **языка системных JSX-диалогов Illustrator** используйте кнопку **«Язык Illustrator / Illustrator language»** внизу панели. У CEP и JSX независимые настройки; смена интерфейсного языка не требует повторного экспорта.

## Командная строка разработчика

```bash
kiki-layout input_copy.json -o result_test.json --mode uniform --families auto \
  --gap 0.8 --margin 2 --rotations 0 --lang ru --svg preview_test.svg
```

Выберите `--lang en` для английских сообщений. CLI-ключи, JSON-поля, идентификаторы и имена файлов всегда остаются английскими для обратной совместимости. Низкоуровневые сообщения библиотек иногда могут быть на английском — такие диагностические ошибки не заменяют понятный статус панели.

## Проверка локализации

- Проверьте «Быстрый старт», «Группировка», «Организация семейств», «Повороты», «Пресеты», «Приоритеты» на обоих языках.
- Раскройте отчёт распознанных семейств и переключите флажок технических ID; имена самих объектов **не переводятся**.
- Сохраните пресет и смените язык: числовые параметры и коды `dense/uniform/ordered` должны остаться прежними.
- При обновлении плагина проверьте, что выбранный язык Illustrator не повлиял на привязку UUID.

Исторические сценарии запуска JSX доступны в `illustrator/`, но отдельное меню «Сценарии → Другой сценарий» не требуется для штатного рабочего цикла CEP.
