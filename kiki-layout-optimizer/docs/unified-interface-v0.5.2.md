# KiKi Models v0.5.2 — Unified Interface Beta

**Статус:** вычислительный движок и панели проверены автономными тестами; требуется испытание CEP + Node.js непосредственно в Illustrator 30.6.0.109 на Windows и на macOS.

## Назначение

Весь основной цикл выполняется внутри **одной CEP-панели Illustrator**:

**Экспорт → ограничения выбранных эмблем → настройка → расчёт с прогрессом → SVG-предпросмотр → применение.**

Никаких команд PowerShell, ручного выбора JSON и отдельного большого окна Python в штатном сценарии **нет**. `src/kiki_layout/gui.py` сохранён в репозитории только как резервный интерфейс. Применение и экспорт вызывают прежние проверенные JSX через `CSInterface.evalScript()`, с receipt подтверждением и UUID объектов.

## Установка Windows

1. Распакуйте релиз в **постоянную отдельную папку**, например `C:\KiKi\kiki-layout-optimizer-v0.5.2`. Не удаляйте v0.5.1 до проверки.
2. Двойным щелчком выполните `install_windows.bat` (создание `.venv`, установка Python/Shapely). Убедитесь, что команда завершилась успешно.
3. Запустите `install_cep_windows.bat`. Он скопирует CEP-панель в `%APPDATA%\Adobe\CEP\extensions\com.kikimodels.layoutoptimizer`; согласитесь на unsigned developer mode, только если хотите использовать неподписанную локальную панель.
4. **Полностью перезапустите Illustrator** (не только закройте панель). В «Окно → Расширения (устаревшие)» откройте **KiKi Layout Optimizer (Unified Beta)**.
5. Откройте тестовую копию макета. Выделите все эмблемы и нажмите «Экспорт выделения». В панели должно появиться имя документа без дополнительного сообщения об успехе от JSX.
6. Отрегулируйте режим, группировку, ориентации, минимальный зазор, отступы, технологию и т. д.
7. При желании выберите часть эмблем **мышью в Illustrator**, поставьте галочку «Не перемещать» или отдельные углы, нажмите «Сохранить правила». Затем «Рассчитать».
8. Наблюдайте прогресс и SVG прямо внутри панели; переключите «Пластина» / «Переходы». После проверки нажмите «Применить в AI» и подтвердите стандартный диалог Illustrator. Сохраните документ под новым именем.

**Важно:** кнопка «Применить» активна только после успешного расчёта *в текущей сессии*. После изменения исходного файла или ограничений рассчитывайте заново. При новом расчёте предыдущий `result_test.json` инвалидируется.

## macOS

Аналогично: `install_macos.command` → `install_cep_macos.command` → **полный перезапуск Illustrator**. CEP установлен в `~/Library/Application Support/Adobe/CEP/extensions/com.kikimodels.layoutoptimizer`. Используется `.venv/bin/python`, без вызова AppleScript/COM. Испытание на Intel и Apple Silicon отдельно требуется.

## Встроенные функции

- **Режим:** Dense / Uniform / Ordered.
- **Семейства:** named / auto / off, индивидуальные запреты поворота и фиксация позиции.
- **Раскладка:** free / rows / columns; расчёт условных переходов nearest / rows / columns / source.
- **Технология:** engraving; experimental cut с положительной шириной пропила. Общий контур реза и CAM пока **не реализованы**.
- **Отступы:** отдельно от четырёх краёв.
- **Пресеты:** `presets/<имя>.json`. Пресеты содержат только параметры, а не объекты и их координаты. Индивидуальные правила — `workspace/<документ>/constraints.json`.
- **Лог:** `workspace/cep-unified.log`; progress сообщает *этап работы*, не точную оценку времени.
- **Результаты:** `workspace/<документ>/input_copy.json`, `result_test.json`, `preview_test.svg`, `route_test.svg`, `route_test.csv`.

## Архитектура и замена CEP на UXP

```text
Illustrator CEP HTML/CSS/JS
  ├── evalScript -> Illustrator JSX export / apply / constraints
  │                     └── файлы и UUID
  └── Node.js child_process.spawn (локально, без Shell и COM)
           └── .venv/bin/python -m kiki_layout.cep_worker <request.json>
                    ├── kiki_layout.gui_jobs.calculate -> core engine
                    ├── события прогресса JSON Lines в stdout
                    └── SVG/JSON в workspace
```

Модуль `cep_worker.py` не импортирует Tkinter и не содержит Adobe-зависимостей. Файловый протокол и ядро используются при будущей миграции на UXP, но замену UI и Node.js-адаптера нужно будет реализовать заново.

Node API CEP включён явно через `--enable-nodejs` и `--mixed-context` (на основании Adobe CEP Cookbook). Расширение работает **локально**; сетевой сервер/порт не открываются. Доступ Node.js к файловой системе считается доверенным только для локальной установленной панели. Публиковать unsigned developer-расширение для массовой установки без отдельного security review и подписывания нельзя.

## Диагностика

- **`CEP Node.js недоступен`:** не включён Node runtime или не перечитан manifest. Запустите установщик CEP и *полностью* перезапустите Illustrator; проверьте `manifest.xml` и `--enable-nodejs`.
- **`Optimizer not installed`:** проверьте успешный запуск `install_windows.bat` и наличие `.venv/Scripts/python.exe` (Windows) или `.venv/bin/python` (macOS).
- **После «Рассчитать» ошибка:** скопируйте статус и `workspace/cep-unified.log`, проверьте, не был ли выбран старый `input_copy.json` из другого документа.
- **Нет предпросмотра:** убедитесь в наличии `preview_test.svg` / `route_test.svg`, напишите точную ошибку CEP. SVG — оценочное представление, не полноценная гарантия готовности для лазера.
- **При отмене:** задача завершает отдельный дочерний Python-процесс, последняя раскладка признаётся недействительной; если ошибка останется, отправьте лог.
- **Не открывается панель:** используйте резервный путь `illustrator/export_selection.jsx` и `illustrator/apply_layout.jsx` через «Файл → Сценарии → Другой сценарий», а расчёт — старым Python GUI. Не изменяйте утверждённые мастер-макеты без копии.

## Что ещё не подтверждено

- Связка *CEP Node.js → Python process* в настоящем Illustrator Windows/macOS.
- Подлинность всех эмблем после перемещения/поворота на сложных AI-файлах (требуется визуальное сравнение).
- Полноценная независимая производственная приёмка резки и гравировки.

До успешного теста в твоём Illustrator это **Unified Beta**, а не финальный промышленный выпуск.
