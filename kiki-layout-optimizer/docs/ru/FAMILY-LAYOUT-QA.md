# Проверка семейств перед публикацией

Рабочие отчёты и идентификаторы приватных документов исключены из публичного снимка. Для воспроизводимых проверок используйте синтетические примеры в examples/ и tests/.

Сравнивайте состав распознанных семейств отдельно от порядка их размещения. Изменение раскладки само по себе не доказывает улучшение распознавания. Нативные проверки Illustrator, установки и удаления остаются незавершёнными; см. RELEASE_RC2.md в этой папке.
