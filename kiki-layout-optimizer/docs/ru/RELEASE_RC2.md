# RC2 — проверка перед публичным релизом

**Основной продукт:** v0.7.2, логика размещения не менялась. Исходники, установщики и проекты пользователей распространяются отдельно.

## Обязательные проверки

- [ ] GitHub Actions CI: Python/JS тесты на Windows и macOS.
- [ ] Windows builder: PyInstaller, portable ZIP, SHA-256, smoke-test реального расчёта.
- [ ] macOS builder: PyInstaller, portable ZIP, SHA-256, smoke-test реального расчёта.
- [ ] Windows: установка портативного архива на чистой системе без Python, проверка CEP в Illustrator 30.6, экспорт → расчёт → применение.
- [ ] macOS: аналогичный нативный тест на совместимой версии Illustrator.
- [ ] Проверка отказа установки после порчи одного файла и сохранения workspace/presets после удаления.
- [ ] Проверка лицензий зависимостей и происхождения логотипа.
- [ ] Сверить фактические SHA-256 опубликованных файлов.
- [ ] Проверить режим установки для неподписанного CEP: только после осознанного согласия.

**Важно:** GitHub Actions сборочные сценарии не являются доказательством реальной работы в Illustrator. Без нативных тестов релиз остаётся кандидатом. Код исполняемых файлов/CEP не подписан.

Публикуем отдельно: GitHub Source ZIP и исходный репозиторий, Windows/macOS portable ZIP, Windows Setup.exe (опционально). Установщик не включён в исходный ZIP. CLI и запуск из исходников документированы.
